# DeskBurn 屏幕风格图鉴

DeskBurn 当前保留两套可独立编译、烧录和发布的屏幕风格。两套页面共享同一套
CC Switch 数据、BLE v3 协议和 NVS 缓存，只改变 320×240 TFT 上的视觉布局。

## 风格总览

| 风格 | 视觉关键词 | PlatformIO 环境 |
|---|---|---|
| Classic | 深色仪表盘、高对比、绿色金额、三栏统计 | `deskburn` |
| Swiss Poster | 瑞士平面海报、暖米白纸张、黑色大字、橙红专色 | `deskburn_swiss` |

## Classic：经典深色仪表盘

![DeskBurn Classic 实机效果](images/deskburn-demo.jpg)

Classic 是 DeskBurn 最初的仪表盘风格：深色背景压低环境干扰，今日金额使用绿色
大字作为视觉中心，本周、本月和总计在底部三栏横向排开。OpenAI 与 Claude 图标、
中文标题以及金额字形均以固件内置 alpha 蒙版绘制。

### 入口

- 源代码：`firmware/deskburn/`
- 构建：`pio run -e deskburn`
- 烧录：`pio run -e deskburn -t upload`
- 快速切换固件：`firmware/releases/DeskBurn-Classic-app.bin`
- 完整固件：`firmware/releases/DeskBurn-Classic-full.bin`

## Swiss Poster：瑞士平面海报

![DeskBurn Swiss Poster 320x240 预览](images/swiss-poster-preview.png)

Swiss Poster 以严格网格、强烈字号对比和极少量专色构成。页面使用 RGB565
`0xF79D` 暖米白纸张色、近黑色文字与橙红色强调线；今日金额左对齐放大，底部三行
表格分别展示本周、本月和总计。按照设计要求，左上角只显示 `DeskBurn` 文字，
没有品牌文字左侧的小图标。

### 入口

- 源代码：`firmware/deskburn_swiss/`
- 资源生成器：`tools/generate_swiss_assets.py`
- 构建：`pio run -e deskburn_swiss`
- 烧录：`pio run -e deskburn_swiss -t upload`
- 快速切换固件：`firmware/releases/DeskBurn-Swiss-Poster-app.bin`
- 完整固件：`firmware/releases/DeskBurn-Swiss-Poster-full.bin`

## 切换风格

已经安装过 DeskBurn 的设备可以直接烧录对应 PlatformIO 环境。Mac 端后台服务会
在设备重启后自动重新连接，不需要更换数据库、设备名或 BLE 配置。

```bash
# 切换到 Classic
pio run -e deskburn -t upload

# 切换到 Swiss Poster
pio run -e deskburn_swiss -t upload
```

从 GitHub 下载二进制后，优先使用 `*-app.bin` 快速切换，它只更新应用分区并保留
NVS。全新或已擦除设备使用 `*-full.bin`。详细地址与 `esptool` 命令见
[`firmware/releases/README.md`](../firmware/releases/README.md)。

## 共享能力

无论使用哪套风格，都保留以下功能：

- 今日、本周、本月和总计的费用与 Token 数据
- 30 秒 BLE 数据推送与自动重连
- 90 秒无有效数据后显示离线状态
- NVS 保存最后一次有效数据
- 内容变化时局部刷新，避免整屏闪烁
